# MILE Visuotactile Sensor

This repository provides the CAD files and fabrication resources
for the fingertip visuotactile sensing module used in:

"MILE: A Mechanically Isomorphic Hand Exoskeleton and Visuotactile Robotic Hand for Data Collection in Dexterous Manipulation"

The released resources include:
- CAD files of the sensor housing and mechanical components
- Bill of materials
- Fabrication instructions

## Sensor Overview

The sensor integrates:
- a miniature RGB camera,
- internal illumination,
- a compliant elastomer layer,

## CAD Files

The STEP files are provided for reproduction and adaptation.
